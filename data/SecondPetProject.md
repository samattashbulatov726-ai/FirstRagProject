# SecondPetProject
# 🏒 NHL Matches Predictor & Streamlit App

Веб-приложение на базе машинного обучения для прогнозирования исходов хоккейных матчей Национальной хоккейной лиги (NHL) на основе актуальной статистики команд.

---

## 📌 Описание проекта
Проект решает задачу бинарной классификации: предсказание победы домашней команды (`1`) или гостевой команды (`0`). В качестве исходных данных используется историческая статистика сыгранных матчей NHL. 

В ходе работы над проектом были реализованы:
1. **Расчет динамических фичей:** Генерация признаков (винрейты, среднее количество забитых/пропущенных шайб, дни отдыха) с привязкой ко времени (lookback-окно в 5 матчей), что исключает утечку данных из будущего.
2. **Сквозные пайплайны (`sklearn.pipeline.Pipeline`):** Автоматическое масштабирование признаков через `StandardScaler` и передача данных в модели.
3. **Оптимизация гиперпараметров:** Подбор лучших параметров для алгоритмов через `GridSearchCV` с 5-фолдовой кросс-валидацией.
4. **Интерактивный интерфейс:** Веб-приложение на `Streamlit`, позволяющее вручную вводить параметры команд и мгновенно получать оценку вероятности победы.

---

## 📊 Используемые признаки (Features)
Для обучения моделей используются только те метрики, которые известны **до начала матча**:
* `home_win_rate` / `away_win_rate` — Общий процент побед команд за последние 5 игр.
* `home_goals_scored_mean_5` / `away_goals_scored_mean_5` — Среднее количество забитых голов за последние 5 игр.
* `home_days_off` / `away_days_off` — Количество дней отдыха команд перед матчем.
* `home_team_win_rate_at_home` — Процент побед хозяев поля в домашних матчах.

---

## 🤖 Модели и Валидация
В проекте сравниваются и настраиваются две топовые модели для работы с табличными данными:
* **XGBoost (`XGBClassifier`)**
* **Random Forest (`RandomForestClassifier`)**

Выбор лучшей модели происходит автоматически на основе метрики `best_score_` после кросс-валидации, после чего она экспортируется в файл `nhlgames2023.joblib`. Качество моделей дополнительно оценивается с помощью ROC-кривых (`RocCurveDisplay`).

---

## 📁 Структура проекта
* `main.py` — Скрипт загрузки данных, предобработки, генерации признаков, обучения моделей через GridSearch и сохранения лучшей модели.
* `app.py` — Веб-интерфейс приложения на Streamlit, использующий сохраненный дамп модели.
* `nhl_games_2023.csv` — Датасет с историей матчей.
* `nhlgames2023.joblib` — Файл сохраненной обученной модели (генерируется после запуска `main.py`).
