# TelcoChurn
📊 Telco Customer Churn Prediction (Прогнозирование оттока клиентов)
Репозиторий содержит решение задачи бинарной классификации для прогнозирования оттока клиентов телекоммуникационной компании на основе датасета Telco Customer Churn.

Проект демонстрирует применение современного подхода к разработке ML-моделей с использованием Scikit-Learn Pipelines, что гарантирует чистоту кода, отсутствие утечки данных (data leakage) и воспроизводимость результатов.

🛠️ Стек технологий
Язык: Python

Анализ и предобработка данных: Pandas, NumPy

Визуализация: Matplotlib, Seaborn

Машинное обучение: Scikit-Learn (Pipeline, ColumnTransformer, GridSearchCV)

🚀 Основные этапы проекта
1. Исследовательский анализ данных (EDA) & Визуализация
Анализ распределения целевой переменной Churn в зависимости от типа контракта (Contract), срока жизни клиента (tenure), ежемесячных платежей (MonthlyCharges) и типа интернет-подключения (InternetService).

Использование boxplot и scatterplot для поиска инсайтов и скрытых закономерностей.

2. Предобработка данных и Feature Engineering
Очистка данных: обработка пропусков и приведение признака TotalCharges к числовому типу.

Создание нового интервального признака TenureGroup (категоризация клиентов по стажу).

Разделение признаков на числовые и категориальные для раздельной трансформации.

3. Построение сквозных пайплайнов (Pipelines)
Для автоматизации и исключения ошибок предобработки был создан ColumnTransformer:

Для числовых признаков: Заполнение пропусков медианой (SimpleImputer) + стандартизация (StandardScaler).

Для категориальных признаков: Заполнение пропусков модой + кодирование (OneHotEncoder).

4. Обучение моделей и Валидация
Данные были разделены на обучающую и тестовую выборки с применением стратификации (stratify=y) для сохранения баланса классов. Были обучены и протестированы две архитектуры:

Logistic Regression (Логистическая регрессия) — в качестве базовой baseline-модели.

Random Forest Classifier (Случайный лес) — для улавливания нелинейных зависимостей.

Для оценки качества использовались метрики: Accuracy, Precision, Recall, F1-score (classification_report).

5. Оптимизация и Анализ важности признаков
Настройка гиперпараметров (n_estimators, max_depth) для Random Forest с помощью кросс-валидации GridSearchCV.

Извлечение и визуализация Feature Importances (топ-10 ключевых признаков, влияющих на уход клиента), что позволяет интерпретировать бизнес-логику модели.

📈 Результаты работы
Код полностью инкапсулирован в пайплайны, что позволяет легко деплоить модель на новые сырые данные.

Получены метрики классификации и определены ключевые триггеры оттока пользователей, которые бизнес может использовать для удержания клиентов.
